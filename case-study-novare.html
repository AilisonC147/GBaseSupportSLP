導入の背景

清水建設は、デジタルを活用したイノベーション施策として「建物との対話」をテーマに様々な取り組みを実施しています。イノベーション拠点「NOVARE」には、スマートビル技術やAI・IoTの先端システムが集積していますが、これらと施設ユーザーを直感的につなぐインターフェースが求められていました。

Phase 1でGBase Supportを活用したAIコンシェルジュの基盤を構築した後、Phase 2ではMCP（Model Context Protocol）Agentを通じて施設内の各システムとAIを連結し、会話するだけでIoTデバイスの操作や社員の位置情報の把握、WowTalkでのメッセージ送付など、より実用的な機能を実現することにしました。

導入前の課題

バラバラなシステム間の連携不足

DX-Core（空調・照明制御）、EmpathicBuilding（位置情報）、WowTalk（社内チャット）など各システムが独立して動作しており、ユーザーは個別アプリを使い分ける必要がありました。

IoT操作の煩雑さ

会議室の空調や照明を操作するには専用画面を開く必要があり、直感的な操作ができませんでした。「会議が終わった」という自然な言葉で照明を消せる体験が求められていました。

リアルタイム情報へのアクセス困難

同僚の現在地確認、天気に応じた外出計画、最新ウェブ情報の取得など、日常業務に必要な情報を得るためのアクション数が多く、生産性向上の妨げになっていました。

GBase Supportを選んだ理由

1

MCPプロトコルによる柔軟なシステム連携

MCP（Model Context Protocol）に対応したAgent設計により、DX-Core、EmpathicBuilding、WowTalkなど既存の社内システムをAIとシームレスに接続できます。新規開発コストを最小化しながら機能拡張が可能です。

2

Chat + Canvasの2つの表示モード

テキスト会話（Chat）とビジュアル表示（Canvas）を柔軟に切り替え。フロアマップ上へのポインター表示や天気予報のグラフ表示など、情報の性質に応じた最適な見せ方を実現します。

3

アクセス権限の柔軟な設定

QRコードのアクセス制限機能により、社員向け（IoT操作・位置情報など高権限機能）と入居者・社外向け（情報閲覧のみ）の2系統を1つのプラットフォームで管理できます。

Phase 2 ユースケース

MCPプロトコルで連携した4つのツールにより、自然な会話で施設のあらゆる情報・操作にアクセスできます。

travel_explore

ウェブサーチ web_search ツール

AIがリアルタイムでウェブ検索を実行し、最新情報を取得して回答します。施設・業界・技術動向など、知識ベースに収録されていない最新情報もカバーします。

活用シーン

「NOVAREの最寄り駅の今の混雑状況を教えて」「最新の建設DX関連ニュースをまとめて」

chat_bubble

WowTalk 連携 wowtalk_send_message_to_member

AIコンシェルジュを通じてWowTalk（社内チャット）にメッセージを送信できます。個人への緊急メッセージ送付、グループへの一括通知など、業務コミュニケーションをAIがサポートします。

活用シーン

「田中さんに『会議室が変更になりました』と送って」「プロジェクトチームに今日の予定変更を一斉通知して」

cloud

天気情報 weather_get_by_location

OpenWeatherMap APIを通じて指定地点のリアルタイム・7日間天気予報を取得します。気温・湿度・降水確率などの詳細情報をCanvas画面にビジュアル表示します。視覚障がいのある方には音声でも対応可能です。

活用シーン

「今週の東京の天気を教えて」「明日の外出には傘が必要？」「潮見周辺の今後7日間の天気を表示して」

settings_remote

IoT制御 + 位置情報 DX-Core / EmpathicBuilding 連携

DX-Coreを通じて会議室の空調・照明をAI経由で操作。EmpathicBuildingの位置情報サービスと連携し、NOVARE Hub 2F・3Fの社員位置をCanvas画面のフロアマップ上にポインター表示します。

活用シーン

「会議室の照明を消して」「第1会議室の温度を2度下げて」「田中さんは今どのフロアにいる？」

今後の展望（Phase 3以降）

NOVARE × GBase Supportの共創プロジェクトはPhase 3以降も継続し、さらなる機能拡張を予定しています。

Phase 3 候補

オープンスペースのAI空調制御

EmpathicBuildingの位置情報とDX-CoreのDefineAreaを組み合わせ、オープンスペースの在室人数に応じた自動空調調整を実現します。「暑い」と言うだけで、AIが位置を確認しながら最適な設定を行います。

Phase 3 候補

パーソナライズされた空調設定

各ユーザーの「快適温度」などの好みをLLMがRAGとして記憶し、空調調整時に自動的にその人が快適と感じる設定を提案・適用。AIがユーザーごとの環境を最適化します。

Phase 3 候補

Empathic Building 全館展開

現在のNOVARE Hub 2F/3Fから対象を全館に拡張し、すべての施設ユーザーの位置情報を活用したサービスを提供。会議室の空き状況確認・予約連携も予定しています。
